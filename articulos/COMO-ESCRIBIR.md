# Cómo agregar un artículo al blog

1. En GitHub, entra a esta carpeta `articulos/` y toca **Add file → Create new file**.
2. Nombre del archivo: el enlace del artículo, en minúsculas, con guiones y terminado en `.txt`.
   Ejemplo: `limpieza-dental.txt` → queda en `/blog/limpieza-dental/`.
3. Copia este molde y cambia el texto:

```
Título: Limpieza dental: cada cuánto hacerla
Resumen: Una o dos frases que se ven en la tarjeta y en Google.
Fecha: 2026-12-01

Primer párrafo. Deja una línea en blanco entre párrafos.

## Un subtítulo
- Un punto de lista
- Otro punto, con una parte en **negrita**
```

4. Toca **Commit changes**. En 1 o 2 minutos el artículo aparece en la página.

- **Programar:** pon una fecha futura. El artículo se publica solo ese día a las 6:15 a. m. (hora de Ecuador). Hasta entonces se puede corregir.
- **Borrador:** si el nombre empieza con `borrador-` (ej. `borrador-limpieza-dental.txt`), no se publica. Para publicarlo, quítale `borrador-` al nombre.
- **Corregir:** abre el archivo, toca el lápiz, cambia y vuelve a hacer *Commit changes*.
- **Quitar:** abre el archivo → menú `…` → *Delete file*.
- Los artículos más nuevos (por fecha) salen primero.
- Información general solamente: que la revise un médico antes de publicarla. Nada de fotos ni datos de pacientes.
